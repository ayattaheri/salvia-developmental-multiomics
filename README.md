# Developmental multi-omics analysis of *Salvia miltiorrhiza* roots

This repository contains the analysis code associated with the study **“Developmental multi-omics profiling of specialized metabolism in *Salvia miltiorrhiza* roots.”**

The study integrates phenotyping, metabolomics, phytohormone profiling, RNA sequencing (RNA-seq), and whole-genome bisulfite sequencing (WGBS) to characterize developmental changes in *S. miltiorrhiza* roots across two growing seasons. Six representative developmental stages were analyzed: 30, 60, 90, 240, 270, and 390 days after germination (DAG).

## Data availability

Raw RNA-seq and WGBS sequencing data are deposited in the National Genomics Data Center (NGDC) under accession number **PRJCA076091**.
